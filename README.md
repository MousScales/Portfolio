# Moustapha Gueye — Personal Portfolio

My personal portfolio website, showcasing my background, experience, technical projects, and interests in software engineering, computer science, and technology.

**Live Website:** [mousholdings.com](https://mousholdings.com)

## Overview

This repository contains the source code for my personal portfolio, designed to provide a central place to learn about my work, explore my projects, and connect with me.

The website is built with React and TypeScript, using Vite for development and production builds.

## Tech Stack

| Technology | Purpose |
|---|---|
| React 18 | Frontend user interface |
| TypeScript | Type-safe development |
| Vite | Development server and build tooling |
| HTML & CSS | Website structure and styling |
| Vercel | Deployment configuration and analytics |

## Getting Started

To run the portfolio locally, follow these steps.

### 1. Clone the repository

```bash
git clone https://github.com/MousScales/Portfolio.git
cd Portfolio
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal.

## Available Scripts

| Command | Description |
|---|---|
| `npm run dev` | Start the Vite development server |
| `npm run build` | Type-check and build for production |
| `npm run preview` | Preview the production build locally |
| `npm run typecheck` | Run TypeScript checks without generating output |

## Project Structure

```text

├── vite.config.ts       # Vite configuration
└── vercel.json          # Vercel configuration
```

## Deployment

The project includes Vercel configuration and uses Vercel Analytics.

To create a production build:

```bash
npm run build
```

The generated production files are placed in the `dist/` directory.
